# 生物记背训练（本地版）

纯静态 PWA：把知识点切成一张张卡，按遗忘曲线推送，一层层揭开回忆。

## 一张卡长什么样

| 字段 | 含义 | 例 |
|---|---|---|
| 术语 / 问题 | 要背的那个点 | 主动运输 |
| 核心答案 | 一句话说清 | 逆浓度梯度、需载体、耗 ATP |
| 要点 | 分条的关键特征 | ① 定义 ② 三个条件 ③ 常见例子 |
| 展开详解 | 一行一步，点标题才展开 | ① 方向 ② 载体 ③ 能量 ④ 例子 |
| 逐层回忆提示 | 点一次出一层，共 N 层 | 1. 属于哪种跨膜方式？ 2. 需要什么？ 3. 耗不耗能？ |
| 每层提示的答案 | 对应提示的结论，默认折叠 | 逆浓度梯度 → 主动运输 |
| 自测问句 | 每问可单独「看答案」 | 为什么协助扩散不耗能？ |

## 使用

- 三档评分：没印象 / 想到一部分 / 张口就来
- 上一轮「没印象」的卡隔几张再出现
- 会的卡点「这条已经会了 · 移出」→ 题库 → 已会 可恢复
- 数据存在本机 IndexedDB（bio-memory-srs），可导出/导入 JSON 备份

## 部署

本目录全部文件（含 icons/）上传到 GitHub 仓库根目录，Settings → Pages → main / root。
